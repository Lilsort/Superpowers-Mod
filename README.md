# Superpowers Mod (Fabric 1.20.1)

A superhero modification for Minecraft 1.20.1 (Fabric) introducing combat abilities inspired by **Invincible** and **The Boys** (Homelander).

---

## ✨ Features

- **⚡ Laser Eyes:** Destructive raycast-based laser beams fired from player eyes. Damages entities, causes combustion, shatters blocks, and plays custom sound and particle effects.
- **🚀 Supersonic Flight:** Supersonic 3D flight with custom physics, acceleration, inertia, travel sound effects, and smooth client-server synchronization.
- **✊ Entity Grab & Throw:** Grab and carry mobs or players through the air and throw them. Includes anti-kick packet handling for high velocity movement.
- **⚙️ Commands:** Full in-game `/sp` administration commands for toggling and customizing superpower parameters.

---

## 🛠️ Requirements & Installation

- **Minecraft:** 1.20.1
- **Mod Loader:** [Fabric Loader](https://fabricmc.net/) (>= 0.15.x)
- **Dependencies:** [Fabric API](https://modrinth.com/mod/fabric-api)

### Building from Source

```bash
git clone https://github.com/Lilsort/Superpowers-Mod.git
cd Superpowers-Mod
./gradlew build
```
Compiled `.jar` will be available in `build/libs/`.
